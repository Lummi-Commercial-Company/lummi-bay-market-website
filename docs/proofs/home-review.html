Scroll inside the frame

Changed · Rewards pill

Now bone fill, navy label. It was cedar with white 11px text — that measured 3.41:1 for the label and 2.43:1 for the fill against the navy header, so it failed twice on every page of the site. Tick “Show the old cedar pill” to compare.

Changed · uppercase labels

“Today's fuel prices” and “Our locations” are navy, not cedar. At 10px cedar measured 3.24:1. Navy measures 7.87:1 at any size.

Blocked · the header logo

The real vector has never reached the repo, and the wordmark is navy on a navy header — Phase 0 items 1 and 2. What you see is a stand-in. This is the one thing that blocks the layout shell, since the header is on every page.

Back-to-top is absent here, correctly

ADR 0011 shows it only after 0.75 of a viewport of scrolling, so a page under 1.75 screens never grows one. Desktop Home is about 1.6. Use the control above to reveal it anyway — real copy will push this page over the line on its own.

Scroll to about a third of the way down

Back-to-top, live

Appears after 500px — 0.75 of this 667px viewport. Press it: the scroll returns to zero and focus moves to the header, so the next Tab does not drop back into the footer. The footer reserves a 78px gutter rather than the button dodging.

One flick restores the fuel block

Nothing in the button knows the block exists. ADR 0005 keys the condense to scroll position, so returning the position returns the card. Watch the bar under the header disappear as you go back up.

Rows, not cards

61px a row against 148px a card. The whole row is the link, so there is no per-row “VISIT”. Same component as desktop, one breakpoint.

Every address and hour here is unconfirmed

Pulled from lcc-lummi.com and never checked with the client — Phase 0 item 3. The card line truncates rather than wraps, and slack past the longest string is 33px at 320px, so hours must come back as 6am–9pm, never 6:00 AM – 9:00 PM.

Not shown, because it does not exist

There is no illustration or photography anywhere on this page. The illustrated layer was built and rejected (ADR 0012), and no art direction has been chosen — Phase 0 item 4, the longest lead time on the critical path. The dashed boxes are where art would land, not a proposal for what it should be.

No Coast Salish motifs have been generated, deliberately. Final art must be authentic or tribe-approved.

Copy is placeholder, and reads as finished

The headline, the sub, and the footer's four column names were all written to fill a layout — loose-ends.md §6 warns someone will ship them by accident. Turn on “Mark placeholder content” to see how much of the page that is.

No promo region on Home

ADR 0007 put the promo on interior pages only; whether Home carries one was never asked and is still open. Home renders none today.
