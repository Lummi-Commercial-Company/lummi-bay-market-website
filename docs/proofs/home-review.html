Scroll inside the frame

Changed · Rewards pill

Now bone fill, navy label. It was cedar with white 11px text — that measured 3.41:1 for the label and 2.43:1 for the fill against the navy header, so it failed twice on every page of the site. Tick “Show the old cedar pill” to compare.

Changed · uppercase labels

“Our locations” and the promo eyebrows are navy, not cedar. At 8.5–10px cedar measured 3.24:1. Navy measures 7.87:1 at any size. The approved proof sets these in cedar; that is the one place this page deliberately departs from it.

Blocked · the header logo

The real vector has never reached the repo, and the wordmark is navy on a navy header — Phase 0 items 1 and 2. What you see is a stand-in. This is the one thing that blocks the layout shell, since the header is on every page.

The block is sticky; the rail is a real grid column

The rail spans grid-row: 1 / span 2 so the block stays with the guest past the hero, and it is pointer-transparent so the full-width sections beneath stay clickable through it. Only the block itself takes events.

Condense is an IntersectionObserver on a 110px sentinel — the block's own resting height — so “scrolled halfway past the block” is literal rather than a tuned number.

Desktop is 1.21 screens, so no back-to-top

154px of scroll against a 555px threshold. Condense fires (it needs the sentinel's 110px); the button does not. Restoring the footer sections, or real copy, puts it back.

Back-to-top, live again

Phone Home is 2.34 screens with the promo region back — close to the 2.25 ADR 0011 measured — so the button appears at 500px on its own. Press it: the scroll returns to zero and focus moves to the header, so the next Tab does not drop back into the footer.

The union rule, live

Open “All prices” at rest and the panel shows Mini Mart and The Cove only — no repeated header row, no caption, because it is a continuation of the card's table. Scroll until the bar appears and open it again: the Truck Stop is now in the panel, and the DEF column comes back with it. The bar carries one Location, so the row it displaced moves below.

Rows, not cards

61px a row against 148px a card. The whole row is the link, so there is no per-row “VISIT”. Same component as desktop, one breakpoint.

Every address and hour here is unconfirmed

Pulled from lcc-lummi.com and never checked with the client — Phase 0 item 3. The card line truncates rather than wraps, and slack past the longest string is 33px at 320px, so hours must come back as 6am–9pm, never 6:00 AM – 9:00 PM.

Not shown, because it does not exist

There is no illustration or photography anywhere on this page. The illustrated layer was built and rejected (ADR 0012), and no art direction has been chosen — Phase 0 item 4, the longest lead time on the critical path. The dashed boxes are where art would land, not a proposal for what it should be.

No Coast Salish motifs have been generated, deliberately. Final art must be authentic or tribe-approved.

Copy is placeholder, and reads as finished

The headline, the sub, and the footer's four column names were all written to fill a layout — loose-ends.md §6 warns someone will ship them by accident. Turn on “Mark placeholder content” to see how much of the page that is.

This version contradicts the locked footer

CLAUDE.md's architecture names the footer's contents explicitly: About, contact form, per-location hours/phone, Rewards, Careers, and the single Lummi Commercial Companies link. Two of those are now absent.

CLAUDE.md is the project's source of truth, so it needs amending to match — otherwise the next session rebuilds both sections from the spec. Hours and phone also still exist per Location in location-content-model; only the footer copy of them is gone.

Promos on Home

ADR 0007 left this open. The approved proof answers it: Home carries three, on the 12-column ladder — half, quarter, quarter. That is what is rendered here.
