One source, four places

Name, summary, amenities, address, phone and hours all come from content/locations/* — the same records behind the Location cards, the footer and the fuel price table. ADR 0009's rule that the location list is derived and never authored per page applies here, or the site grows a second set of hours to forget about.

What an editor writes

The intro sentence. That is all. Changing a phone number is a Location edit, made once, and this page follows.

The Truck Stop is listed separately

It shares Exit 260's address and is a different store with different customers, so it gets its own block rather than a line inside Exit 260's. Same reasoning that makes it its own row in the fuel table.

Every address, phone and hour here is unconfirmed

Pulled from lcc-lummi.com and never checked with the client — Phase 0 item 3. This page is where a wrong number does the most damage, so it should be the first thing verified.

The summaries are placeholder

summary is a new field on the Location schema, added by ADR 0015. What is written here fills the layout; the real one or two sentences come from the business.

The Truck Stop has no phone of its own

It currently shows the Exit 260 number. If drivers should reach the truck side directly, that is a second number to collect — and a field the schema does not have yet.
